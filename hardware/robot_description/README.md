# Robot description

Chhaya's kinematic and inertial model. The training code reads the URDF and meshes from here (through the
`training/robot_hardware` link).

| File | |
|---|---|
| `urdf/chhaya.urdf` | **The whole robot**: 20 revolute joints (12 leg + 8 arm), with the chest, head and claws as fixed mass. Generated by `../tools/build_description.py` from `Robot.urdf` plus the parametric CAD: do not edit by hand |
| `chhaya_mass.json` | Mass budget of the generated links, per link and per item |
| `urdf/Robot.urdf` | The legs, hips and torso, as exported from Fusion 360 with [fusion2urdf](https://github.com/syuntoku14/fusion2urdf), with xacro includes for materials, transmissions and Gazebo. Source for the leg links of `chhaya.urdf` |
| `urdf/robot_flat.urdf` | The same URDF without the xacro includes. Loads in any URDF tool (urdf-loader, PyBullet, MuJoCo, ikpy) |
| `urdf/materials.xacro`, `Robot.trans`, `Robot.gazebo` | The exporter's extras that `Robot.urdf` includes |
| `meshes/*.stl` | One mesh per link, in millimetres (the URDF scales them by 0.001). The generated links also have `<link>_servos.stl` (servo bodies, visual) and `<link>_col<i>.stl` (convex collision pieces) |

## Joints

Frame: X forward, Y left, Z up. Legs (both sides; the left/right axes are mirrored):

| Joint | Parent → child | Axis | Range (rad) |
|---|---|---|---|
| `l_hip_yaw` / `r_hip_yaw` | base_link → hip_upper | ±Z | ±0.785 |
| `l_hip_roll_joint` / `r_hip_roll_joint` | hip_upper → hip_lower | ±X | −0.436 … 1.571 |
| `l_hip_pitch_joint` / `r_hip_pitch_joint` | hip_lower → thigh | Y | ±1.571 |
| `l_knee_joint` / `r_knee_joint` | thigh → calf | −Y | ±2.094 |
| `l_ankle_roll_joint` / `r_ankle_roll_joint` | calf → ankle | ±X | ±1.396 |
| `l_ankle_pitch_joint` / `r_ankle_pitch_joint` | ankle → foot | Y | −0.611 … 1.484 |

Arms: `shoulder_pitch`, `shoulder_roll`, `arm_yaw` and `elbow` per side (see `chhaya.urdf`), and a fixed
`imu_joint` at the BNO055. Masses are in `chhaya_mass.json`: 2.423 kg in all.

## Changing the description

- **Chest, head, arms, claws:** change `../cad/parametric/chhaya_cad.py` and run `../regenerate.sh`. It
  rebuilds `chhaya.urdf`, the meshes, the MuJoCo model and the USD, and reruns the fit and strength checks.
- **Legs:** re-export `Robot.urdf` from Fusion 360 keeping the link and joint names, regenerate
  `robot_flat.urdf` (strip the `xmlns:xacro` attribute and the three `<xacro:include>` lines), update the
  inertials copied into `training/envs/assets/robotV2/robot_v2.xml`, then run `../regenerate.sh`. The trained
  policies depend on the leg geometry, so this means retraining.
